# CGI Artist Portfolio — GitHub Pages Ready

A polished, responsive dark editorial CGI artist portfolio with LinkedIn links, a creative process section, and cinematic visual design. Static HTML/CSS/JavaScript; no build tools required.

## Personalize it
1. Open `index.html` and replace `YOUR NAME` / `YOURNAME` with your name or studio.
2. Replace `hello@example.com` with your real email.
3. Replace each project's demo image URL (`images.unsplash.com/...`) with your own render paths, e.g. `assets/chrome-objects.webp`. Create an `assets` folder for your images.
4. Change project titles, project descriptions, categories, and portfolio links.
5. Replace `YOUR-LINKEDIN-USERNAME` in every LinkedIn link with your actual LinkedIn profile slug (e.g. `https://www.linkedin.com/in/jane-doe/`). The site links to your profile; it does not request LinkedIn account access.
6. Remove skills you don't use and add your own.

**Note:** Sample project images are third-party placeholder photos/artworks, not original CGI work or claims of your work. Replace all of them before publishing a professional portfolio. The hero and about visuals are generated with CSS and can also be replaced by your own renders.

## Publish on GitHub Pages
1. Create a public GitHub repository, e.g. `cgi-portfolio`.
2. Upload `index.html` to the repository root (and your `assets` folder if using local images).
3. Open repository **Settings → Pages**.
4. Choose **Deploy from a branch**, select **main** and **/(root)**, then save.
5. Your portfolio will appear at `https://YOUR-USERNAME.github.io/cgi-portfolio/` once GitHub completes deployment.

For a root personal site, name the repository `YOUR-USERNAME.github.io`.
